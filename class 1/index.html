CSS First Class:

Three Types Of CSS:


External CSS:

External CSS is a method of writing CSS code in a separate .css file and linking it to an HTML document using the link tag in the head section. This allows you to apply the same styles to multiple HTML pages without repeating the code in each file.

Example:

If you change the button color in style.css, it will automatically change on every page that is linked to that file. In short: External CSS = "Write once, use everywhere"

Internal CSS:

Internal CSS is a method of writing CSS code inside the style tag within the head section of a single html document. This CSS only applies to that one html page.

Inline CSS:

Inline CSS is a method of writing CSS code directly inside the style attribute of an HTML tag. It applies styling to only that specific HTML element.

Types Of Selector:

Universal Selector.

All element applies in webpage

* {}

Type Selector.

Matches element names

h1 , h2 , h3 {}

Class Selector.

Matches an element whose class attribute

. class{}

ID Selector.

Matches an element whose id attribute

# id {}

Child Selector.

Matches an element that is a direct child of another

div > p {}

Descendant Selector.

Matches an element that is a descendent of another specified element not just a direct child of that element

p a {}
